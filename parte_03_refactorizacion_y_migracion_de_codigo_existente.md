# Parte 3: Refactorización y migración de código existente

En esta parte final del libro, primero aprenderás sobre las reglas de los Hooks, que sirven como base para crear tus propios Hooks personalizados. Luego, aprenderás en profundidad cómo refactorizar el código de nuestra aplicación de blog existente para utilizar Hooks personalizados donde tenga sentido hacerlo. Finalmente, migrarás un proyecto existente de componentes de clase de React a React Hooks y aprenderás cómo se comparan ambas soluciones.

Esta parte contiene los siguientes capítulos:

- [Capítulo 11](https://subscription.packtpub.com/book/web-development/9781836209171/11): Reglas de los Hooks (*Rules of Hooks*)
- [Capítulo 12](https://subscription.packtpub.com/book/web-development/9781836209171/12): Creación de tus propios Hooks (*Building Your Own Hooks*)
- [Capítulo 13](https://subscription.packtpub.com/book/web-development/9781836209171/13): Migración desde componentes de clase de React (*Migrating from React Class Components*)
