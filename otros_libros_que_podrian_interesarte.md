## React Key Concepts, Second Edition

**Autor:** Maximilian Schwarzmüller  
**ISBN:** 978-1-83620-227-1  

- Construir aplicaciones web modernas, reactivas y fáciles de usar.
- Crear componentes y utilizar props para transferir datos entre ellos.
- Manejar eventos, realizar actualizaciones de estado y gestionar contenido condicional.
- Añadir estilos de forma dinámica y condicional para crear interfaces de usuario modernas.
- Usar técnicas avanzadas de gestión del estado como la API Context de React.
- Utilizar React Router para renderizar diferentes páginas según la URL.
- Comprender las mejores prácticas clave y las oportunidades de optimización.
- Aprender sobre React Server Components y Server Actions.

## Modern Full-Stack React Projects

**Autor:** Daniel Bugl  
**ISBN:** 978-1-83763-795-9  

- Implementar un backend utilizando Express y MongoDB, y realizar pruebas unitarias con Jest.
- Desplegar aplicaciones web full-stack usando Docker, configurar CI/CD y pruebas end-to-end con Playwright.
- Añadir autenticación mediante JSON Web Tokens (JWT).
- Crear un backend GraphQL e integrarlo con un frontend usando Apollo Client.
- Construir una aplicación de chat basada en una arquitectura orientada a eventos con Socket.IO.
- Facilitar la optimización para motores de búsqueda (SEO) e implementar renderizado del lado del servidor (SSR).
- Utilizar Next.js, un framework full-stack empresarial, con React Server Components y Server Actions.
